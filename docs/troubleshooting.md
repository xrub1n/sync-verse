# SyncVerse Troubleshooting Guide

## Purpose

This document tracks common setup, development, pipeline, MFA, and JSON output issues for SyncVerse MVP 1.

At the start of development, this file is intentionally lightweight. As real issues come up, developers and AI agents should add concrete problems, causes, and fixes here.
